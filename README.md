# QuickBasket

**Groceries. Essentials. Delivered.**

A grocery and essentials delivery platform. The AI shopping assistant is a *feature inside* QuickBasket, not the brand.

| Folder | What it is | Status |
|---|---|---|
| [`backend/`](backend/README.md) | ASP.NET Core Web API (.NET 10), SQL Server, JWT auth, Razorpay payment module | Implemented, **not yet compiled or run** |
| [`frontend/`](frontend/README.md) | React 19 + TypeScript + Vite + Tailwind | Folder structure and placeholders only |
| [`PROJECT_PROGRESS.md`](PROJECT_PROGRESS.md) | What is done, what is pending, how to resume | Keep updated |

Payments run in **test mode only** (mock provider by default, Razorpay test keys optional). Live keys are blocked in code until onboarding is approved.
